# Basic POS System (CodeIgniter 4)

## Project Name
Basic Point-of-Sale (POS) System — Laboratory Activity for IT0049 (Web System Technologies)

## What This Project Does
A simple POS system built with CodeIgniter 4 that displays customer and user/staff
records. This version uses static PHP arrays as temporary data — no database is
connected yet.

## Requirements
- PHP 8.1 or higher
- Composer
- PHP extensions: `intl`, `zip`, `mbstring`
